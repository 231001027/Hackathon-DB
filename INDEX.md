## 🚀 Deployment Quick Links

### Vercel (Recommended)
```bash
npm i -g vercel
vercel --prod
```
📖 [Full Guide](./DEPLOYMENT_CHECKLIST.md#vercel-deployment-recommended)

### Netlify
```bash
npm i -g netlify-cli
netlify deploy --prod --dir=dist
```
📖 [Full Guide](./DEPLOYMENT_CHECKLIST.md#netlify-deployment)

### Traditional Server
```bash
npm run build
scp -r dist/ user@server:/var/www/
```
📖 [Full Guide](./DEPLOYMENT_CHECKLIST.md#traditional-server-deployment)

### Docker
```bash
docker build -t hackathon-portal .
docker run -p 80:80 hackathon-portal
```
